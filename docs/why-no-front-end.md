# Views without a front end

This desk answers deduction questions from records, produces review packs and renders three read-only HTML views. The operator changes records through the commands and keeps supporting originals in private document storage.

A screen adds mobile data entry, drag and drop and shared interactive editing. The free desk has none of these, no offline sync, no distributor portal collection and no dispute submission. HTML outputs are snapshots, not live screens. Enterprise DNA builds agreed connections and screens into a customer's version.

The embedded database is for one local operator at a time. Shared use needs private PostgreSQL hosting, authenticated access, backup and restore checks and a least-privilege service role. The supplied owner connection bypasses row-level security. --actor records attribution, not identity verification. Do not expose that connection to a browser.

Export snapshots are portable records, not a tested full restore mechanism. Back up the database and evidence files together and test recovery before operational use.
